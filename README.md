**Status:** Early Development

Celem nie jest projekt „na ocenę", lecz coś, co da się dalej rozwijać.

## O projekcie

Gra 2D tworzona w Unity. Projekt łączy programowanie, projektowanie mechanik i budowę własnego świata gry, z naciskiem na naukę dobrych praktyk pracy nad większym projektem programistycznym. Ma być łatwy do stopniowej rozbudowy o nowe mechaniki, poziomy i funkcje.

## Założenia

- Gra 2D w Unity
- Dobrze działające, interesujące mechaniki
- Własny świat i styl gry
- Uporządkowana struktura kodu
- Testowanie i poprawianie błędów
- Stopniowy rozwój wraz z nabywaniem umiejętności

## Plan rozwoju

**Etap 1 — Fundamenty**
Konfiguracja projektu, podstawowa struktura gry, system gracza, poruszanie, pierwsze mechaniki, poziom testowy.

**Etap 2 — Gameplay**
Rozwój mechanik, przeciwnicy/interakcje, system poziomów, UI, punktacja/postęp, podstawowe SFX/VFX.

**Etap 3 — Zawartość**
Kolejne poziomy, dodatkowe mechaniki, rozbudowa świata, balans, optymalizacja.

**Etap 4 — Finalizacja**
Testy, poprawki błędów, dopracowanie grafiki i dźwięku, optymalizacja, wersja do udostępnienia.

## Technologie

- Unity — silnik gry
- C# — język programowania
- Git / GitHub — kontrola wersji i współpraca

Lista może się rozszerzyć wraz z potrzebami projektu.

## Podejście do kodu

Czytelne nazewnictwo, podział na komponenty odpowiedzialne za konkretne zadania, unikanie duplikacji, komentarze przy trudniejszych fragmentach, regularny refaktor. Nie wszystko będzie idealne od razu — nauka poprawiania kodu też jest częścią projektu.

## Współpraca

Zmiany wprowadzane przez osobne branche i pull requesty.

## Aktualny cel

Dojść od pustego projektu Unity do pierwszego grywalnego prototypu.
